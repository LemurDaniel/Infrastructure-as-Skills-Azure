# Virtual Machine - what the question set cannot express

## Fixed at creation

- **The name.** A Windows computer name is limited to 15 characters; the resource name is
  the computer name unless set apart, and a rename is a recreate.
- **The OS type and the image generation.** A Linux machine does not become a Windows one,
  and a generation 1 machine does not become generation 2.
- **Trusted launch.** Neither added later to a machine without it nor removed from one with
  it (the machine is recreated on a new disk).
- **The zone, or the availability set.** Moving between zone, set and neither means
  recreating the machine; the machine's data disks are in its zone.
- **The administrator user name.**
- **The home region**, and with it which sizes, zones and disk types exist.

## Ordering

The subnet, the disk encryption set and its key (for `customer_managed`), the availability
set, the Recovery Services vault and its policy, the Key Vault for a Windows password, then
the machine with its network interface, then the extensions, then the role assignments on the
machine, then the backup protection and the shutdown schedule. The role for the Entra sign-in
is a role *on* the machine and needs the machine first; the first login is possible only after
the role has propagated, which can take minutes.

## Pitfalls

**The modules disagree on defaults.** Encryption at host (Terraform on, Bicep off), and
the patch mode, which neither module sets (both leave it empty and assess with `ImageDefault`)
- a machine that renders without it is patched by the guest's own updater. Accelerated
networking is off in the Terraform module. Every decision is written on the call.

**Encryption at host needs a subscription feature.** `Microsoft.Compute/EncryptionAtHost`
must be registered on the subscription (`az feature register` and a provider re-register) or
the deployment fails with an error that names the feature. It is a platform preparation,
not a stage of the template.

**One machine in a zone is a placement, not redundancy.** Two machines in two zones behind a
load balancer are redundancy. A single machine's SLA is the best Azure offers for one
instance and needs premium disks throughout.

**The Entra login needs three things.** The extension, the system-assigned identity, and a
role on the machine for each person or group. A missing role reads as a permission-denied
sign-in; a missing identity as an extension that never reports healthy. On Windows the
client machine must also be Entra-joined or registered for passwordless sign-in.

**Auto-shutdown deallocates and stops there.** The schedule only stops the machine. Starting
it again in the morning is a person or an automation, and a stopped machine that holds a
static public or private address keeps paying for the address.

**A key generated by the module is in the state.** With `generate_admin_password_or_ssh_key`
the private key or password is a state value as well as a vault secret. The Linux path
supplies the public key and so keeps the private key away from the state; the Windows path
cannot, and the state must be protected as the vault is.

**Backup needs the vault in the same region** and a policy that exists when protection is
configured; a protection configured against a missing policy fails at apply, not at plan.

**Guest monitoring is not a diagnostic setting.** The platform diagnostic setting carries
metrics. Logs, performance counters and the update compliance of the guest need the Azure
Monitor Agent and a Data Collection Rule, which this set neither installs nor creates.

**Patching by platform needs the VM agent** running in the guest. A custom image with the
agent removed makes the patch orchestration fail quietly.

## Not covered here, and why

Spot priority and eviction, dedicated hosts and host groups, capacity reservations,
hibernation, ultra disks and write accelerator, domain join and DSC, custom script and
run-command, the Azure Monitor Agent and Data Collection Rules, Defender for Servers,
just-in-time access, Bastion and the image build pipeline each
carry decisions of their own and have no question set; a request for one is said out loud,
not improvised. The patch window is the `maintenance-configuration` set; this set assigns the
machine to it. A machine behind a load balancer is wiring, owned by a pattern; the second
machine of a zone-redundant pair is a second instance of this set.
